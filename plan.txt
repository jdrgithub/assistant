🔐 SECURITY MODEL

All document ingestion, chat history, and personal data live on your webserver only.

RunPod is used like a secure compute microservice:

Upload only sanitized or minimal data (text chunks, prompts)

Receive embedding vectors or LLM completions

Auto-shutdown when job is done

All LLM calls (even external like OpenAI/Claude) go through your own API

📦 EMBEDDING PIPELINE (With RunPod)

Local webserver detects new/updated document.

Splits into chunks (LangChain/TextSplitter).

SSH/API call to RunPod pod:

python embed.py input.json output.json

Uses sentence-transformers or bge-small-en

Pull output.json back.

Store vectors in Qdrant, tag with metadata.

💬 LLM COMPLETION PIPELINE (With RunPod or Claude)

Assistant wants to generate a response with long-term context.

Query Qdrant for top-k docs.

Compose assistant prompt:

Inject role (e.g. music coach)

Inject current context + RAG results

Send to:

RunPod-hosted local model (Ollama, LLaMA, etc)

or to GPT-4/Claude via backend-controlled call

Return answer, log it to chat history
